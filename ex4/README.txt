EXPERIMENT 4 - PROJECT MANAGEMENT DASHBOARD

Features:
- Add tasks and assign employees
- Set priority and deadline
- View task status and summary
- Mark tasks In Progress or Completed
- Delete tasks
- Store tasks in a JSON file through the backend

Requirements: Node.js

Run:
1. Extract the ZIP file.
2. Open terminal inside EX4_Project_Management_Dashboard.
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000 in your browser.

Run npm install once for this project.
